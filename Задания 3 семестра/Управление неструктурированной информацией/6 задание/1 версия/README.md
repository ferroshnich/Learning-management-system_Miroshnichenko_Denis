MLP_XOR_Miroshnichenko
Код программы для решения задачи XOR при помощи многослойного персептрона (MLP).
Цель программы — показать, как нейронная сеть с одним скрытым слоем способна классифицировать данные, которые невозможно разделить одной прямой.

Задача XOR является классическим примером нелинейной задачи, которую линейный персептрон решить не может.
Однако многослойный персептрон легко справляется с этим благодаря скрытому слою и нелинейным функциям активации.

Как работает программа
1. Генерирует синтетические данные XOR
Создаются четыре группы точек вокруг координат:
(0, 0)
(0, 1)
(1, 0)
(1, 1)
Метка вычисляется как логическая операция XOR:
y = x1 XOR x2
Для реалистичности добавляется небольшой шум.

2. Строит нейронную сеть
Используется MLP из двух слоёв:
скрытый слой с ReLU
выходной слой с Sigmoid
Каждый слой обучается методом градиентного спуска.

3. Выполняет прямое и обратное распространение (backpropagation)

На каждом шаге:
считаются выходы слоёв,
вычисляется ошибка (MSE),
обновляются веса и смещения.

4. Визуализирует работу сети

После обучения программа рисует 4 панели, показывающие:

1. Исходные данные XOR ( Распределение точек по двум классам)
2. Активации скрытого слоя (ReLU) (Значения, которые получаются после первого слоя.
Они показывают, как пространство “искривляется”)
3. Выход сети (Sigmoid) (Вероятность принадлежности классу 1.)
4. Решающее пространство MLP (Окончательное разделение классов, созданное нейронной сетью)

Принцип работы многослойного персептрона
Вход
Каждая точка имеет два признака (x₁, x₂).
Скрытый слой (ReLU)
Нелинейность ReLU "ломает" пространство, позволяя сети разделять данные, которые невозможно разделить прямой.
Выходной слой (Sigmoid)
Преобразует результат в значение от 0 до 1.
Обучение
Каждый шаг обучения включает:
вычисление предсказаний,
сравнение с реальными метками,
уменьшение ошибки с помощью градиентного спуска.

Почему MLP решает XOR
Линейный персептрон строит только одну прямую, поэтому с задачей XOR он не справляется.
Два класса данных переплетены так, что их невозможно разделить одной границей.

MLP же:
создаёт новые представления данных в скрытом слое,
разделяет пространство нелинейными преобразованиями,
успешно классифицирует XOR даже при большом шуме.

Этапы работы скрипта:
1. Генерация данных
generate_xor_data(n_samples, noise)
2. Обучение MLP
train_mlp_interactive(X, y, hidden_neurons, eta)
3. Визуализация процесса обучения по эпохам
4. Построение итоговых 4 графиков
данные XOR
карта ReLU
карта Sigmoid
итоговое разделение
