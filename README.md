# Репозиторий заданий 3 семестра  
### Мирошниченко Денис

---

## 📘 Описание проекта

Данный репозиторий реализует систему хранения и контроля выполнения заданий **3 семестра**.  
Все дисциплины и задания объединены в единую структуру — **формат Monorepo**,  
что позволяет преподавателю видеть историю изменений и версий отчётов каждого задания.

Структура:
Задания 3 семестра/
├── Онтология/
│ ├── 1 задание/
│ │ ├── 1 версия/
│ │ └── 2 версия/
│ ├── 2 задание/
│ └── ...
├── Управление ИТ-проектами/
└── Управление неструктурированной информацией/
